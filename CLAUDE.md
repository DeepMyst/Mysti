# Claude Code entry point

Read [AGENTS.md](AGENTS.md) for repository guidance, source-of-truth rules and
validation commands. It is the canonical working guide for coding agents.

Use [the documentation map](docs/README.md) to choose a task guide,
[navigation.json](docs/navigation.json) for structured discovery, and
[llms.txt](llms.txt) for raw Markdown links.

For implementation work, start with [architecture](docs/ARCHITECTURE.md) and
[developer notes](docs/DEVELOPER-NOTES.md), then inspect the relevant source.
Use [production readiness](docs/PRODUCTION_READINESS.md) for current evidence
and open acceptance work; historical plans and demo captures are not proof of
current native-provider behavior.
