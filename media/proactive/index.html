Before you start

Check a selected responsibility for related work before making a decision. Your optional task summary orders existing evidence locally; it is never saved or sent to DeepMyst or a coding provider.

Enable a connected responsibility to check its context.

Local repositories

Opt in per workspace. Mysti checks local Git refs every minute while this editor is running. File contents stay on this machine; remote refs update only when you fetch.

Connected work

DeepMyst checks the exact repository or channel you choose, even when this editor is closed. Watching never authorizes messages, commits, or other actions. Pause or remove cloud watches before signing out if you want server monitoring to stop.

Watch a topic

Matches use these terms in PR titles/descriptions or recent channel messages. A match suggests relevance; it does not prove someone is doing the same task. Each check reads up to 100 open/closed PRs or 15 Slack top-level messages, then continues from saved progress. Slack uses a seven-day window; replies are excluded. Scan status shows pending pages and coverage gaps.

Your insight inbox

Cloud evidence is retained for 30 days; the inbox displays the latest 100 insights. Check the source before acting on older evidence.

Notifications and control

At most 3 summaries per workspace per day, between 08:00 and 20:00 in this machine’s timezone, while Mysti is running. Notifications contain no source excerpts. Your inbox still updates during quiet hours.

Mobile push, phone alerts, email/calendar monitoring, automatic testing, and delegated actions are not available in this release.
